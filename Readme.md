# Sales Dashboard - Excel

## Project Overview
This project is an interactive Sales Dashboard built in Microsoft Excel to analyze sales performance and support business decision-making.

## Key Metrics
- Total Revenue
- Total Profit
- Total Orders
- Profit Margin

## Features
- Interactive Slicers
- Dynamic Charts
- KPI Cards
- Monthly Sales Analysis
- Product Category Performance
- Regional Sales Insights

## Tools Used
- Microsoft Excel
- Pivot Tables
- Pivot Charts
- Slicers
- Data Cleaning


## Business Insights
- Identified top-performing products.
- Analyzed monthly revenue trends.
- Compared sales performance across regions.
- Tracked profitability and growth.
